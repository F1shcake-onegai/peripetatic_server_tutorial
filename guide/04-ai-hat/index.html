Check the kernel version

Section titled “Check the kernel version”

If the version is 6.15 or newer, installing hailort-pcie-driver ended with an error: the driver still uses del_timer_sync, which newer kernels removed.3 Fix the driver with one of these options. If the version is older, skip them.

  • Patching Driver Source
  • Downgrading Kernel (not recommended)

Patch the driver source

Section titled “Patch the driver source”

The last command shows the changed line in linux/vdma/monitor.c.

Rebuild the driver

Section titled “Rebuild the driver”

make all ends with LD [M] hailo1x_pci.ko, and the last command prints Hailo PCIe Driver Installed!. The warning missing 'System.map' file from make install is harmless.

Kernel 6.12.18 still has del_timer_sync, so the driver builds without changes.

Downgrade the kernel

Section titled “Downgrade the kernel”

The holds stop apt from replacing the downgraded kernel. After the reboot, uname -r shows 6.12.18-v8-16k+.

Build the kernel headers

Section titled “Build the kernel headers”

Run these in the same terminal:

make -s kernelrelease must show the same version as uname -r.

Build the driver

Section titled “Build the driver”

If asked whether to use DKMS, answer yes. DKMS builds the driver for kernel 6.12.18.

To undo the downgrade later, run sudo apt-mark unhold with the same packages, then sudo apt install --reinstall linux-image-rpi-2712 raspi-firmware, and reboot.
