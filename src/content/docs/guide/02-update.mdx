---
title: "2. Update and Upgrade"
---

## Update the package list {/* .step */}

```bash
sudo apt update
```

This downloads the latest list of available packages and versions. It doesn't install anything yet.

## Upgrade the installed packages {/* .step */}

```bash
sudo apt full-upgrade
```

When prompted `Do you want to continue? [Y/n]`, press <kbd class="key-y">Y</kbd> and then <kbd class="key-enter">Enter</kbd>. This also updates the Linux kernel and firmware. Use `full-upgrade` rather than `upgrade`, because Raspberry Pi OS changes package dependencies more often than Debian does.[^1]

:::note[Not enough disk space?]
If `full-upgrade` reports that it needs more space, check your free space with:

```bash
df -h
```

To make room, delete old downloaded package files with:

```bash
sudo apt clean
```
:::

## Reboot {/* .step */}

```bash
sudo reboot
```

[^1]: [https://www.raspberrypi.com/documentation/computers/os.html](https://www.raspberrypi.com/documentation/computers/os.html)
