This chapter is for a Raspberry Pi 5 with the AI HAT+ 2 (Hailo-10H), running 64-bit Raspberry Pi OS (Trixie).[^1] Mount the AI HAT+ 2 first, as described in [0. Hardware Preparation](../00-hardware/#ai-hat-2).

## Update the bootloader {/* .step */}

```bash
sudo rpi-eeprom-update -a
sudo reboot
```

## Run LLMs with hailo-ollama

<Tabs syncKey="hailort">

```bash
sudo apt install dkms
sudo apt install hailo-h10-all
```

```bash
sudo reboot
```

```bash
hailortcli fw-control identify
```

The output shows the details of the AI HAT+ 2. `Serial Number`, `Part Number` and `Product Name` might show `<N/A>`. This is expected.

```bash
wget https://dev-public.hailo.ai/2025_12/Hailo10/hailo_gen_ai_model_zoo_5.1.1_arm64.deb
sudo dpkg -i hailo_gen_ai_model_zoo_5.1.1_arm64.deb
```

<TabItem label="Using v5.3.0 (for newer models and htop monitoring)">

v5.3.0 is Hailo's own release. It adds the `qwen3:1.7b` model.[^2]

### Remove the Raspberry Pi Hailo packages {/* .step */}

If you installed v5.1.1 before, remove its packages first. They conflict with Hailo's packages.

```bash
sudo apt remove hailo-h10-all
sudo dpkg --force-all --purge python3-h10-hailort
sudo dpkg --force-all --purge h10-hailort-pcie-driver
sudo dpkg --force-all --purge h10-hailort
sudo dpkg --force-all --purge hailo-gen-ai-model-zoo
```

### Install DKMS and the kernel headers {/* .step */}

If this is a fresh install, run:

```bash
sudo apt update
sudo apt install dkms linux-headers-rpi-2712
```

### Download and install v5.3.0 {/* .step */}

```bash
cd /tmp
wget https://dev-public.hailo.ai/2026_04/Hailo10/hailort_5.3.0_arm64.deb
wget https://dev-public.hailo.ai/2026_04/Hailo10/hailort-pcie-driver_5.3.0_all.deb
wget https://dev-public.hailo.ai/2026_04/Hailo10/hailo_gen_ai_model_zoo_5.3.0_arm64.deb
sudo dpkg -i hailort_5.3.0_arm64.deb
sudo dpkg -i hailort-pcie-driver_5.3.0_all.deb
sudo dpkg -i hailo_gen_ai_model_zoo_5.3.0_arm64.deb
```

### Check the kernel version {/* .step */}

```bash
uname -r
```

If the version is 6.15 or newer, installing `hailort-pcie-driver` ended with an error: the driver still uses `del_timer_sync`, which newer kernels removed.[^3] Fix the driver with one of these options. If the version is older, skip them.

<Tabs syncKey="kernel-fix">
<TabItem label="Patching Driver Source">

#### Patch the driver source {/* .step */}

```bash
cd /usr/src/hailort-pcie-driver
sudo find . \( -name "*.c" -o -name "*.h" \) \
  -exec sed -i 's/\bdel_timer_sync\b/timer_delete_sync/g' {} +
grep -rn "timer_delete_sync" --include=*.c .
```

The last command shows the changed line in `linux/vdma/monitor.c`.

#### Rebuild the driver {/* .step */}

```bash
cd /usr/src/hailort-pcie-driver/linux/pcie
sudo make clean && sudo make all
sudo make install
sudo dpkg --configure hailort-pcie-driver
```

`make all` ends with `LD [M] hailo1x_pci.ko`, and the last command prints `Hailo PCIe Driver Installed!`. The warning `missing 'System.map' file` from `make install` is harmless.

</TabItem>
<TabItem label="Downgrading Kernel (not recommended)">

Kernel 6.12.18 still has `del_timer_sync`, so the driver builds without changes.

#### Downgrade the kernel {/* .step */}

```bash
sudo apt update
sudo apt install -y rpi-update
sudo rpi-update 3608b77cd4557513506dbc098db04938439804aa
sudo apt-mark hold linux-image-rpi-2712 linux-image-rpi-v8 \
                   linux-headers-rpi-2712 linux-headers-rpi-v8 \
                   linux-image-$(uname -r) linux-image-$(uname -r | sed 's/2712$/v8/') \
                   raspi-firmware
sudo reboot
```

The holds stop `apt` from replacing the downgraded kernel. After the reboot, `uname -r` shows `6.12.18-v8-16k+`.

#### Build the kernel headers {/* .step */}

Run these in the same terminal:

```bash
KREL=$(uname -r)
FWHASH=$(cat /boot/firmware/.firmware_revision)
KCOMMIT=$(curl -fsSL https://raw.githubusercontent.com/raspberrypi/rpi-firmware/$FWHASH/git_hash)
S=/usr/src/linux-$KREL

sudo apt install -y git bc bison flex libssl-dev libelf-dev build-essential dkms

sudo mkdir -p "$S" && sudo chown "$USER" "$S" && cd "$S"
git init
git remote add origin https://github.com/raspberrypi/linux.git
git fetch --depth=1 origin "$KCOMMIT"
git checkout FETCH_HEAD

sudo modprobe configs
zcat /proc/config.gz > .config
curl -fsSL -o Module.symvers \
  https://raw.githubusercontent.com/raspberrypi/rpi-firmware/$FWHASH/Module_2712.symvers

make olddefconfig
make -j"$(nproc)" modules_prepare
make -s kernelrelease

sudo ln -sfn "$S" /lib/modules/$KREL/build
```

`make -s kernelrelease` must show the same version as `uname -r`.

#### Build the driver {/* .step */}

```bash
sudo dpkg --configure hailort-pcie-driver
```

If asked whether to use DKMS, answer yes. DKMS builds the driver for kernel 6.12.18.

To undo the downgrade later, run `sudo apt-mark unhold` with the same packages, then `sudo apt install --reinstall linux-image-rpi-2712 raspi-firmware`, and reboot.

### Start the Hailo Ollama server {/* .step */}

```bash
hailo-ollama
```

The server runs on port 8000. Leave it running, and open a second terminal for the next steps.

### Download a model {/* .step */}

List the available models:

```bash
curl --silent http://localhost:8000/hailo/v1/list
```

Download a model, replacing `<model>` with a model from the list, e.g. `qwen2:1.5b`:

```bash
curl --silent http://localhost:8000/api/pull \
     -H 'Content-Type: application/json' \
     -d '{ "model": "<model>", "stream" : true }'
```

### Chat with the model {/* .step */}

Replace `<model>` with the model you downloaded:

```bash
curl --silent http://localhost:8000/api/chat \
     -H 'Content-Type: application/json' \
     -d '{"model": "<model>", "messages": [{"role": "user", "content": "Translate to French: The cat is on the table."}]}'
```

<details>
<summary>(Optional) Chat in a browser with Open WebUI</summary>

Open WebUI doesn't run on Python 3.13, which Raspberry Pi OS Trixie uses, so it runs in Docker.

### Install Docker {/* .step */}

```bash
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-doc podman-docker containerd runc | cut -f1)
sudo apt update
sudo apt install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Create the Docker package source:

```bash
sudo nano /etc/apt/sources.list.d/docker.sources
```

Add these lines:

```
Types: deb
URIs: https://download.docker.com/linux/debian
Suites: trixie
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
```

Install Docker and check that it works:

```bash
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl start docker
sudo groupadd docker
sudo usermod -aG docker $USER
newgrp docker
docker run hello-world
```

### Run Open WebUI {/* .step */}

Make sure the Hailo Ollama server is running, then run:

```bash
docker pull ghcr.io/open-webui/open-webui:main
docker run -d -e OLLAMA_BASE_URL=http://127.0.0.1:8000 -v open-webui:/app/backend/data --name open-webui --network=host --restart always ghcr.io/open-webui/open-webui:main
docker logs open-webui -f
```

Open WebUI can take up to a minute to start. Press <kbd class="key-control">Ctrl</kbd>+<kbd class="key-c">C</kbd> to stop following the log. Then open `http://127.0.0.1:8080` in a browser on the Pi, or `http://<hostname>.local:8080` from another computer.
